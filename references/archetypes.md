# Portfolio Archetypes Blueprint

Every profession requires a tailored portfolio structure. This document provides the layout blueprint, specialized widgets, and key sections for each major archetype.

---

## 1. Software Engineer / Developer / Systems Architect

### Primary Goal
Prove code quality, system complexity handling, problem-solving, and shipping capability.

### Essential Sections
1. **Hero**:
   * Status badge: `"🟢 Available for Senior SWE Roles"`.
   * Title, elevator pitch, primary tech stack badges.
   * Actions: `"View Projects"`, `"Download Resume"`, `"Copy Email"`.
2. **Terminal / Interactive Code Widget**:
   * Simulated interactive command line showing `whoami`, `skills --list`, `experience --recent`.
3. **Featured Projects (Bento Grid)**:
   * Project card featuring architecture diagram or UI screenshot.
   * Tech stack tags (`Go`, `Docker`, `PostgreSQL`, `React`, `AWS`).
   * Key outcome metric: `"Handles 50k req/s with 99.99% uptime"`.
   * Live Demo button + GitHub Source button.
4. **Work Experience Timeline**:
   * Company, Title, Dates, Location.
   * Impact-driven bullet points (using the Google XYZ formula: *Accomplished [X], as measured by [Y], by doing [Z]*).
5. **Technical Skills Matrix**:
   * Languages, Frameworks, Cloud & DevOps, Databases, Testing/Tooling.
6. **Open Source & Writing**:
   * GitHub repositories with star counters.
   * Technical blog post links (Medium, Dev.to, or Substack).
7. **Contact & Socials**:
   * GitHub, LinkedIn, Twitter/X, Email, GPG Key or Cal.com booking link.

## 2. Video Editor / Motion Graphics Artist / Colorist

### Primary Goal
Showcase visual mastery, storytelling speed, sound design impact, and audience retention metrics immediately.

### Essential Sections
1. **Cinematic Hero**:
   * Bold headline: `"Crafting High-Retention Visual Stories for Creators & Global Brands"`.
   * Large, prominent **"Watch 2026 Showreel"** primary action button with play icon.
   * Key stats counter bar: `"50M+ Views Generated"`, `"250+ Videos Delivered"`, `"15+ Brands Partnered"`.
2. **Interactive Video Showreel / Player Modal**:
   * Click-to-play popup modal with YouTube/Vimeo embed or HTML5 video container.
   * Fullscreen playback capability.
3. **Selected Works Grid**:
   * Filter tabs: `"All"`, `"YouTube Long-Form"`, `"Shorts / Reels"`, `"Commercials"`, `"Motion Graphics"`.
   * Video thumbnail cards with duration badge, view count badge (`"🔥 2.4M Views"`), and client name.
   * Hover-to-play preview or click-to-watch modal.
4. **Before & After Breakdown (Color Grading / VFX)**:
   * Interactive slider or side-by-side comparison showing Raw Log footage vs. Final Grade / VFX composited shot.
5. **Tools & Workflow Software**:
   * Adobe Premiere Pro, After Effects, DaVinci Resolve Studio, Blender, Photoshop, Audition.
6. **Client Logos & Testimonials**:
   * Logos of prominent creators, agencies, or brands worked with.
   * Quotes from directors or channel owners praising turnaround speed and retention boosts.
7. **Production Booking / Rate Card Inquiry**:
   * Availability indicator: `"Taking on 2 Projects for Next Month"`.
   * Direct inquiry form / Calendly call button / WhatsApp or Email button.

## 3. UI/UX & Product Designer

### Primary Goal
Demonstrate user-centered thinking, design system craftsmanship, problem definition, and measurable product outcomes.

### Essential Sections
1. **Hero**:
   * Clean, typography-forward headline.
   * Value statement: `"Designing intuitive software, design systems, and delightful digital products"`.
2. **Featured Case Studies (Deep Dives)**:
   * Large visual cards highlighting real client or product work.
   * Breakdown tags: `"Problem"`, `"My Role"`, `"Outcome"`.
   * Key metrics: `"+38% Checkout Conversion"`, `"-45% Onboarding Drop-off"`.
   * "Read Case Study" link leading to detailed walkthrough or Figma link.
3. **Interactive Design System Preview**:
   * Component library showcase (buttons, toggles, form states, color tokens).
4. **Design Philosophy / Process**:
   * 4-step framework: *Discover & Research → Wireframe & Prototype → Test & Iterate → Ship & Maintain*.
5. **Toolbox**:
   * Figma, FigJam, Framer, Principle, Webflow, Design Tokens, UserTesting.
6. **Endorsements & Recommendations**:
   * Quotes from Product Managers and Engineering Leads on cross-functional collaboration.

## 4. Content Creator / Digital Marketer

### Primary Goal
Demonstrate audience growth, engagement rates, brand deal execution, and conversion power.

### Essential Sections
1. **Hero**:
   * High-energy portrait, channels handled, follower count totals.
2. **Audience & Reach Dashboard**:
   * Metrics cards: Monthly Impressions, Total Followers, Average Engagement Rate, Demographics.
3. **Brand Collaborations Showcase**:
   * Carousel or grid of sponsored videos, newsletters, or campaigns.
   * Conversion metrics: `"Sold out inventory in 4 hours"`, `"CTR of 8.2% across 3 newsletters"`.
4. **Services & Media Kit**:
   * Dedicated video sponsorships, TikTok/Reels packages, newsletter ads, speaking engagements.
   * "Download Media Kit (PDF)" button.

---

## 5. Student / Career Switcher / Junior Specialist

### Primary Goal
Highlight hunger to learn, self-driven passion projects, clean code / fundamentals, and transferable skills.

### Essential Sections
1. **Hero**:
   * Honest, enthusiastic headline: `"Aspiring Software Developer passionate about building accessible web experiences"`.
   * Availability: `"Actively seeking Entry-Level or Internship opportunities"`.
2. **Deep-Dive Passion Projects**:
   * 2 to 3 well-documented projects with detailed README, live deployed URL, and test coverage.
   * Reflection snippet: *"What I learned building this"* and *"What I would improve in v2"*.
3. **Learning Timeline & Roadmap**:
   * Timeline of courses completed, certifications earned, and daily coding streaks.
4. **Transferable Skills & Background**:
   * Prior professional experience re-framed for the new domain (e.g. project management, communication, analytical problem solving).
