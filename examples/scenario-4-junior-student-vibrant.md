# Test Scenario 4: Junior Developer / Student with No Resume (Bright & Vibrant)

This scenario tests an entry-level candidate who has no formal corporate resume and wants a bright, approachable, modern portfolio highlighting hackathons, courses, and GitHub passion projects.

---

## 👤 User Profile & Prompt

**User Prompt:**
> "I just graduated in CS and don't have a professional resume or company experience yet. Can I still make a portfolio? I want something bright, colorful, and friendly with my projects and skills."

---

## 🤖 AI Execution Steps

1. **Intake Processing & Reassurance**:
   * AI assures the user:
     > *"Absolutely! For an entry-level developer or recent grad, an authentic, project-centric portfolio is often far more impressive than a generic resume. Let's showcase your problem-solving abilities, GitHub projects, and learning velocity."*

2. **Progressive Intake for Juniors**:
   * **Core Projects**: 2-3 passion projects with live URLs and GitHub source.
     * E.g., *Algorhythm: Audio Visualizer Web App* (Web Audio API, React, Canvas).
     * E.g., *CampusMarket: Student Peer-to-Peer Marketplace* (Next.js, Prisma, SQLite).
   * **Hackathons & Competitions**: E.g., *"1st Place @ University Hackathon 2025"*.
   * **Learning Journey & Daily Streaks**: GitHub streak badge, LeetCode / problem solving focus.

3. **Style Selection**:
   * Recommends: **Bright & Vibrant / Playful Neo-Aesthetic**.
   * Soft lavender/indigo background, pill badges, friendly emojis, animated bounce hovers, and accessible color contrast.

4. **Outcome**:
   * AI structures a "Why Hire Me" section highlighting fast learning capacity and curiosity.
   * Direct GitHub repo cards and clickable project demos.
